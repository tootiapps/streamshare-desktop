# Public scope

This repository contains the public source of the StreamShare desktop playback
receiver for Windows, macOS and Linux.

The supported public surface consists of:

- documented desktop receiver behavior;
- compatibility with the published StreamShare remote protocol;
- source code, tests and build scripts present in this repository;
- signed installers, checksums and notices attached to official releases.

Undocumented internals are not stable APIs. Application internals, unpublished
integrations, private test fixtures, credentials and signing material are not
part of this repository or its public contract.
